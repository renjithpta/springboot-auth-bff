# Configuration reference

All values are Spring environment properties; credentials have no committed fallback. `scripts/init.py` creates development-only values. Explicit environment values override `.env` in native execution. Compose passes `.env` into the identity/BFF containers; edit Compose environment entries for topology changes. Kubernetes ConfigMaps hold non-secrets; Secrets hold credentials.

| Variable | Default / meaning |
|---|---|
| AUTH_ISSUER | `http://127.0.0.1:9000`; stable public token issuer |
| AUTH_INTERNAL_URL | Same locally; internal identity address for BFF/API backchannels |
| AUTH_PORT | 9000 |
| AUTH_DB_URL | File-backed H2; separate DB per identity instance |
| AUTH_DB_USER | `sa` for H2 |
| AUTH_DB_PASSWORD | Required private configuration |
| SIGNING_KEY_PATH | `.runtime/signing.pem`; persistent RSA PKCS8 key |
| BFF_CLIENT_ID | `aobp-bff` |
| BFF_CLIENT_SECRET | Required confidential-client credential |
| BFF_CALLBACK | `http://localhost:8080/login/oauth2/code/platform` |
| BFF_LOGOUT | Registered post-logout URI; OIDC provider endpoint available, BFF UI performs local logout only |
| APP_URL | BFF's allowlisted successful-login destination |
| BFF_PORT | 8081 |
| REDIS_HOST / REDIS_PORT | localhost / 6379 |
| REDIS_PASSWORD | Required |
| TOKEN_ENCRYPTION_KEY | Base64 of exactly 32 random bytes; shared by all BFF replicas |
| ACCESS_TOKEN_TTL | PT2M; PT10S for fast refresh testing |
| REFRESH_TOKEN_TTL | PT30M; rotating refresh tokens |
| COOKIE_SECURE | false for local HTTP only; true behind approved production HTTPS |
| FLIGHT_URL / FLIGHT_PORT | localhost:8082 / 8082 |
| API_AUDIENCE | flight-api; must match the issuer's token customization |
| GATEWAY_PORT | 8080 |
| BFF_URL / UI_URL | Gateway upstream addresses |
| DEMO_USERS | false by application default; generated development .env enables fixtures |
| DEMO_PASSWORD | At least 16 characters; generated by init; used only to seed missing fixtures |
| UPSTREAM_CLIENT_SECRET | Local simulator's confidential client credential |
| SPRING_CONFIG_ADDITIONAL_LOCATION | Optional external provider YAML |

The issuer's audience and business policy are deliberately code-owned in this sample. Changing an audience requires updating issuer and resource-server contracts together, not merely editing a UI value. Changing DEMO_PASSWORD does not reset passwords of existing DB users. Use controlled account administration instead.

## Ports and routing

8080: browser application/gateway; 9000: identity public endpoint; 9001: optional provider simulator; 8081: private BFF; 8082: private Flight API; 5173: native static UI; 6379: Redis. Kubernetes and Docker UI listen on 8080 internally. Native scripts currently use these documented demo ports for readiness checks; editing individual PORT variables also requires adjusting readiness URLs in the runner.

## Configuration changes

Restart affected processes after changing configuration. Keep BFF client secret synchronized between issuer and BFF. All replicas require the same encryption key; an uncontrolled key change makes existing Redis records unreadable. Back up identity data and signing keys together. Never reuse dev credentials in another environment.
